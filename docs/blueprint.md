# **App Name**: Gigalight

## Core Features:

- Dynamic Multi-Role Dashboard: A centralized UI that seamlessly toggles between Worker, Business, and Validator interfaces based on user profile settings.
- Omni-Gig Market: Unified discovery board for micro-tasks with varying proof requirements and complex freelance projects requiring milestone bidding.
- AI Submission Auditor tool: A generative AI tool that analyzes uploaded proofs—including text, images, or links—and assists validators by highlighting discrepancies or suggesting an approval status based on task guidelines.
- Bidding & Escrow Management: Workflow system to place project bids using bid balances, with integrated escrow status indicators to show when funds are 'Held' or 'Released'.
- Satoshi Wallet Integration: Virtual wallet ledger to track earnings and payouts in SATs, supporting simulated Blink (Lightning) and Lumicash top-up flows.
- Integrated Interview Manager: Dashboard for tracking job applications, scheduling interviews, and managing real-time project messaging between clients and freelancers.
- Referral & Policy Engine: System to manage referral tracking and platform fee distributions (Worker, Validator, Referral, and Platform shares) for every completed task.

## Style Guidelines:

- Primary color: Electric Violet (#8457F1), chosen for a digital, high-energy 'Lightning Network' aesthetic. Background color: Deep Charcoal (#131217), creating a premium dark-themed environment that minimizes eyestrain for high-concentration work.
- Accent: Deep Sky Blue (#3C62FF) to provide analogous contrast for actionable items and status badges. Secondary backgrounds: Dark Navy Mist (#1A1B23).
- Font Pairing: 'Space Grotesk' for headlines to evoke a computerized, tech-forward vibe, paired with 'Inter' for body text and long descriptions to ensure maximum readability and objective clarity.
- Ultra-modern thin-line icons with a subtle neon glow effect when active, particularly for Satoshi-denominated amounts and lightning transactions.
- Modern dashboard architecture using side-panel navigation and 'glassmorphism' card elements with 1px border highlights to define information hierarchies clearly.
- Subtle, non-distracting 'pulse' animations for active project slots and smooth slide transitions when switching between account types.
